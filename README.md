A program that writes the single sentence that could have replaced an entire pointless meeting, entered in make.fun's "The Meeting That Should Have Been One Line".

## The entry

> We've all read the proposal and we all agree, so let's approve it, email the decision to everyone, and give us back the hour this meeting was going to waste.

One sentence, 157 characters. It does the meeting's whole job in one breath: shared ground (everyone read it, everyone agrees), the decision, the distribution — and then it reclaims the wasted hour. The sting is in the last clause: the meeting is not just unnecessary, it is the thing that was going to waste the hour.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (one line, no trailing newline). Running it twice produces byte-identical output.
